# Skyrim Library for Android
**This repository hosts the Android app for Skyrim Library. For the main Skyrim Library project, please refer to [Skyrim Library](https://github.com/Nuozhu2333/SkyrimLibrary/).**
***
*Your pocket Tamriel study room.*

Whenever and wherever you are, the Skyrim Library project lets you delve into the untold secrets and forbidden knowledge of Tamriel. With the Skyrim Library Android App, accessing this wealth of lore is now quicker and easier than ever.  Built with Kotlin, this app offers the following features:
- **Free & Open Source** – Just like Skyrim Library itself, this project is free and open source. Anyone can use it without any conditions or restrictions.
- **Fully Offline** – The Skyrim Library Android App has been designed from the ground up to work completely offline. You don't need to worry about network connectivity or data usage – simply download the offline book collections to your device and you're ready to go.
- **Community-Driven Content** – With the Skyrim Library project, you can freely choose from various book collections, which offer different languages and translations, allowing you to select according to your preferences.
- **Flawless Displa**y – The Skyrim Library Android App now supports multiple constructed languages from the game, along with English, Simplified Chinese, Traditional Chinese, and more languages incoming.
