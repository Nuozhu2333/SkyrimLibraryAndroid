# 天際圖書館 Android 程式
**此倉庫為天際圖書館 Android 應用程式。天際圖書館主項目請訪問 [Skyrim Library](https://github.com/Nuozhu2333/SkyrimLibrary/).**
***
*你的掌上泰姆瑞爾書房。*

- **免費且開源** - 正如天際圖書館一樣，此項目免費且開源，任何人都可以無條件地使用它。
- **完全离线** - 天際圖書館 Android 程式自誕生之初便設計為可以完全脫機使用。您無需擔心任何網絡連接或流量資費問題，只需要將離線書庫下載到本地即可。
- **社群支援** - 藉助天際圖書館項目，你可以自由選擇不同的書庫，它們提供了不同的語言與譯本，允許您根據喜好自由選擇。
- **完美顯示** - Skyrim Library Android 程式現已可顯示多種遊戲中人造語言，並支援英文、簡體中文、繁體中文等多種語言。
