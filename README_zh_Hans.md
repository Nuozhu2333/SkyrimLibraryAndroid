# 天际书库 Android 应用
**此仓库为天际书库 Android 应用。天际书库主项目请见 [Skyrim Library](https://github.com/Nuozhu2333/SkyrimLibrary/).**
***
*你的掌上泰姆瑞尔书房。*

- **免费且开源** - 正如天际书库一样，这个项目免费且开源，任何人都可以无条件地使用它。
- **完全离线** - 天际书库 Android 应用自诞生之初便设计为可以完全离线使用。您无需担心任何网络连接或流量资费问题，只需要将离线书库下载到本地即可。
- **社区支持** - 借助天际书库项目，您可以自由选择不同的书库，它们提供了不同的语言与译本，允许您根据喜好自由选择。
- **完美显示** - 天际书库 Android 应用现已可显示多种游戏中人造语言，并支持英文、简体中文、繁体中文等多种语言。
